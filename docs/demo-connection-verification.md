## ログイン方法

### モック閲覧端末（FR-028/029、AT-10）

`npm run db:demo:devices` で3つのデモ店舗専用の閲覧端末を追加する。サーバー専用キーを使う開発用スクリプトであり、開発Project ID・URL・リンク先の一致を検査する。コードは暗号学的乱数32バイト、DBにはSHA-256のみ保存する。ローカルの `.env.demo-devices.local` はGit対象外。再実行時に既存コードを保持し、失効済み端末を自動復活させない。コードファイル紛失時は管理画面から再発行する。

3端末の登録と、公開キー・未ログイン状態の `store_device_snapshot` による店舗ID照合が成功した。接続画面は `/station`。個人ログイン・編集権限は付与しない。既存のDB統合試験で匿名閲覧範囲・秘密列非公開・失効を検証する。

`http://localhost:3000/login` を開く。ローカルの `.env.demo-accounts.local` にメールアドレス一覧と `INITIAL_PASSWORD` を保存した。このファイルと `.env.local` は Git 除外を確認済み。パスワードは資料・コンソールへ転記しない。

最初は `INFORMATION_SYSTEMS_EMAIL` のアカウントでログインし、パスワードを変更する。その後、店舗・端末管理で対象店舗の端末コードを発行し、`/station` で登録すると通常の店舗閲覧を使用できる。各業務の操作には該当ロールの個人アカウントを使用する。

投入後に `.env.local` の `ALLOW_DEMO_DATA_SETUP` と `DEMO_SEED_AUTH_USERS` は `false` に戻した。追加投入が必要な場合のみ明示的に有効にする。初期パスワード変更後は、保存されている初期パスワードではそのユーザーにログインできない。
