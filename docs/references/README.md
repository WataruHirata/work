# 参照資料

実行時には読み込まれない、改修時の比較・検討に使う資料をここへ置きます。

| 資料                         | 用途                                                                                            |
| ---------------------------- | ----------------------------------------------------------------------------------------------- |
| [ui-refresh](./ui-refresh/)  | UI刷新時に受領した比較用TSX・CSS。実際に採用したコードは `src/components/preview/` を確認する。 |
| [図表資料](../diagrams/)     | 画面遷移図、業務フロー図、ER図などの編集可能な原本。                                            |
| [要件資料](../requirements/) | 業務要件の一次資料と履歴資料。                                                                  |

このディレクトリのコード断片はアプリケーションに組み込まれません。実装を修正する場合は、対応する `src/` のファイルとテストを変更します。
## MySQL接続設定資料

[mysql-connection](./mysql-connection/) は、MySQL接続設定時に受領した比較用スキーマ・実装断片です。実際に採用したコードは `database/mysql/` と `scripts/` を確認してください。
