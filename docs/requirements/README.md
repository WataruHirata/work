# 要件資料

このディレクトリは、業務要件の一次資料と履歴資料を集約した場所です。実装・設計の判断は、次の優先順で行います。

1. [統合要件書v3](./みのり屋_販売管理システム_統合要件書_v3.md) の第25章にある最新回答
2. ユーザーからの明示的な追加指示
3. [最終統合完全版](./みのり屋_販売管理システム_要件定義書_最終統合完全版.md) と [最終統合版](./みのり屋_販売管理システム_要件定義書_最終統合版.md) の履歴情報

要件と実装の対応は、親ディレクトリの[要件照合](../requirements-v3-audit.md)で確認します。画面遷移図は本来 `docs/diagrams/画面遷移図1.drawio` に置きますが、現在の作業ツリーには存在しません。復元または再追加されるまで、[ルート設計](../routes.md)を画面構成の参照先とします。
